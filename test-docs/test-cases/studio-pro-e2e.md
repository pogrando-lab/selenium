## TC-ACC-002 - Создание кастомного аксессуара

**Priority:** High  
**Preconditions:** Каталог открыт; пользователь авторизован или функция создания доступна без авторизации.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть форму создания кастомного аксессуара. | Отображаются поля названия и цены. |
| 2 | В поле названия оставить 2 символа. | Система не принимает название; отображается ошибка минимальной длины. |
| 3 | Ввести название длиной ровно 3 символа. | Название принято. |
| 4 | Указать цену ниже допустимого диапазона. | Отображается ошибка: цена должна быть от 10 до 2000 долларов. |
| 5 | Указать цену 10 долларов. | Минимальная допустимая цена принята. |
| 6 | Указать цену 2000 долларов. | Максимальная допустимая цена принята. |
| 7 | Указать цену, например 2001 доллар. | Кастомный аксессуар не создается; отображается ошибка максимального значения. |
| 8 | Ввести корректное название и допустимую цену в диапазоне 10-2000 долларов, затем сохранить. | Аксессуар создан, появляется в таблице или каталоге и доступен для добавления в корзину. |

## TC-DOC-001 - Квитанции и документы

**Priority:** Medium  
**Preconditions:** Раздел документов открыт.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Попытаться загрузить файл налогового сертификата с расширением `.pdf` или `.jpg`. | Файл отклоняется. Остаются разрешенными только `.txt`, `.csv`, `.json`. |
| 2 | Попытаться загрузить корректный `.txt`, `.csv` или `.json` размером больше 512 КБ. | Файл отклоняется с сообщением о превышении размера. |
| 3 | Загрузить валидный файл `.txt`, `.csv` или `.json` размером не больше 512 КБ. | Файл принят. Отображаются имя файла, размер и статус готовности к проверке. |
| 4 | Нажать кнопку проверки сертификата. | Сертификат проверяется. Отображается понятный статус успешной проверки или причина отклонения по содержимому. |
| 5 | Нажать кнопку скачивания чека. | Загружается файл чека в формате `.txt`. Файл сохраняется и содержит данные транзакции. |
| 6 | Нажать кнопку скачивания каталога. | Загружается файл каталога в формате `.csv`. Файл сохраняется и содержит корректные разделенные запятыми данные каталога. |
