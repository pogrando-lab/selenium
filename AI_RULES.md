# AI QA Engineering Rules

- Бери требования строго из файлов в директории `test-docs/`.
- Не добавляй новые пользовательские сценарии и не меняй указанные ограничения без явного запроса.
- Для UI-автотестов используй паттерн Page Object Model.
- Размещай классы страниц в пакете `com.studio.pro.pages`.
- Размещай тестовые классы в пакете `com.studio.pro.tests`.
- Базовые настройки тестов храните в `src/test/resources/config.properties`.
- Не хардкодь URL в Page Object или тестовых классах. Используй `Configuration.baseUrl` или значения из конфигурации.
- Наследуй UI-тестовые классы от `com.studio.pro.TestsBase`.
- Используй JUnit 5 и Selenide.
- Формулируй проверки через стабильные локаторы, явные ожидаемые состояния и минимально хрупкие сценарии.
